# Автобухгалтерия

Телеграм-бот для чата друзей: ловит траты на машину прямо в переписке, раскладывает
их по категориям и раз в месяц кидает картинку с топом транжир.

## Что умеет

**Ловит траты из обычных сообщений.** Никаких команд: пишете «бенз 2000» или
«мойка 500р» — бот отвечает «На тачку?» с кнопками. На голое число не реагирует:
нужно слово про машину рядом, иначе он бы дёргал чат на каждую сумму. Автор жмёт «Да», бот удаляет
свой вопрос, вешает 🫡 на исходное сообщение и кладёт трату в базу. Дорогие траты
получают 🔥 (от 10 000) и 💀 (от 50 000).

**Пять категорий:** ⛽ бензин · 🔧 ремонт и ТО · 🚨 штрафы · 🧽 уход · 🏛 государство.
В «государство» идут парковки, платные дороги, налог, страховка и техосмотр, в
«уход» — мойки, омывайка, дворники и аксессуары. Старое «остальное» при первом
запуске новой версии разносится по словам из заметки, а что не узналось — в уход.

**Учится словам вашего чата.** Слово, которого бот не знает, заводится явной
формой «на тачку 3000 гидрач» — трата запишется сразу, а слово запомнится. После
двух подтверждений «гидрач 3000» работает само. Что накопилось — `/lexicon`.

**Считает расход.** Если писать «заправка 42л 2800 пробег 123456», бот посчитает
литры на 100 км и стоимость километра. Пробег не обязательно писать на каждой
заправке: литры заправок без пробега тоже учитываются, а опечатки в одометре
отсекаются сами.

**Рисует картинки.** Ежемесячный топ со сменой мест, разбивкой по категориям,
титулами и тремя самыми дорогими тратами. Плюс личная карточка по `/me`.

**Следит за пробегом и ТО.** Достраивает текущий пробег между редкими замерами,
считает цену километра по всем тратам, а не только по бензину, и пишет в личку,
когда подходит срок замены. Интервалы настраиваются там же, в личке.

## Пробег и обслуживание

Замер пробега можно писать отдельным сообщением — `пробег 123456` — или внутри
траты: `заправка 42л 2800 пробег 123456`.

Между замерами бот достраивает пробег сам: считает средний километраж в день по
отрезкам между соседними замерами, причём свежие отрезки весят больше (период
полураспада — 90 дней). Пересел на метро или сменил работу — оценка подтянется
за пару недель, а не будет тянуть прошлогодний темп. Достроенные цифры всегда
помечены тильдой: `~124 300 км`.

Цена километра считается по окну между первым и последним замером, и в числитель
идут только траты, попавшие внутрь этого окна. Это защита от «20 000 ₽ на ТО при
10 км известного пробега»: под траты вне окна просто нет километров. Пока окно
короче 1000 км, 30 дней или трёх замеров, цифра помечается как ненадёжная.

Напоминания приходят в личку владельцу, когда до замены осталось меньше 500 км
или двух недель. Порог по километрам плавающий: тому, кто наматывает по 200 км в
день, 500 км хватило бы на двое суток, поэтому запас считается как две недели
езды по его собственному темпу.

Замену удобнее всего отмечать прямо из траты. Если в ней есть масло, фильтры,
колодки, свечи, антифриз и т. п., после «Да» вопрос превращается в «Отметить
замену в ТО?» с галочками по найденным позициям и подставленным пробегом — из
сообщения, а если его там нет, то прикинутым по темпу езды. Не совпал — ответьте
на сообщение числом, и это заодно станет настоящим замером одометра. Та же
форма приходит под напоминанием в личке и открывается кнопкой «Заменил» в
карточке позиции. Отметка замены сбрасывает старый план «следующая на …».

Интервал можно задать двумя способами — «меняли на таком-то пробеге» или
«следующая замена запланирована на такой-то». Второй нужен, когда прошлая замена
неизвестна. Тормозная жидкость, антифриз, страховка и техосмотр отслеживаются по
времени, а не только по километрам.

## Команды

| Команда | Что делает |
|---|---|
| `/top` | итоги текущего месяца картинкой |
| `/top 06.2026`, `/top июнь`, `/top прошлый` | итоги нужного месяца |
| `/me` | личная карточка: полгода трат, расход топлива, прогноз |
| `/undo` | удалить последнюю свою трату (или ответом на сообщение с тратой) |
| `/car Camry 2007` | указать машину, на которую идут траты |
| `/cars` | весь парк чата: человек — машина — пробег |
| `/to` | настроить, что и когда менять (открывает личку) |
| `/lexicon` | какие слова бот выучил в этом чате |
| `/detect` | журнал детектора: на что реагировал, на что молчал, CSV |
| `/export` | все траты в CSV |
| `/chatid` | id чата, чтобы вписать его в `CARBOT_ALLOWED_CHATS` |

## Деплой

Один скрипт: тянет свежий код, пересобирает образ, перезапускает контейнер.

```bash
bash start
```

Первый раз на чистом сервере:

```bash
git clone <repo> tg-car-moneycount-bot && cd tg-car-moneycount-bot && cp .env.example .env && nano .env && bash start
```

Токен от [@BotFather](https://t.me/BotFather) вписывается в `.env`, который в
репозиторий не едет и живёт только на сервере. Без него `start` остановится с
понятным сообщением, не подняв контейнер.

База встроенная и лежит в `data/` — каталог примонтирован томом, поэтому
переживает и пересборку образа, и `docker compose down`. Бэкап — обычное
копирование папки:

```bash
tar czf carbot-backup-$(date +%F).tar.gz data/
```

Логи ротируются сами (3 файла по 10 МБ):

```bash
docker compose logs -f
```

## Локальная разработка

```bash
python3 -m venv .venv && .venv/bin/pip install -e ".[dev]" && cp .env.example .env
```

Шрифты уже лежат в `assets/fonts`, пересобирать их не нужно. Скрипт
`scripts/prepare_fonts.py` пригодится, только если захочется другой шрифт или
другие веса.

```bash
.venv/bin/python -m carbot
```

### Важно: privacy mode

По умолчанию телеграм-боты **не видят обычные сообщения в группах** — только
команды и ответы себе. Без этого бот не поймает ни одной траты:

@BotFather → `/setprivacy` → выбрать бота → **Disable** → убрать бота из чата и
добавить заново.

Бот сам проверяет это на старте и ругается в лог, если privacy mode включён.
Ещё ему нужно право ставить реакции и удалять свои сообщения — проще всего дать
права администратора.

## Как устроено

| Слой | Файлы | Смысл |
|---|---|---|
| Парсинг | `parsing/` | суммы, категории, морфология, литры и пробег |
| База | `db/` | SurrealDB: схема и все запросы |
| Пробег | `mileage.py`, `cost.py` | оценка пробега и цена километра |
| Обслуживание | `service.py` | каталог позиций, сроки замен, пороги напоминаний |
| Гараж | `garage.py` | сборка машины, пробега и ТО для всех потребителей |
| Отчёты | `reporting.py`, `titles.py` | ранги, титулы, расход, прогнозы |
| Рендер | `render/` | сборка SVG и растеризация в PNG |
| Бот | `handlers/`, `scheduler.py` | хендлеры, личный кабинет, крон |

### Детект без LLM

Три слоя, каждый добирает то, что не поймал предыдущий:

1. **Сумма.** Регулярка понимает `1000р`, `1 500`, `15.000`, `2к`, `1.5k`,
   `500 рублей`, «косарь». Отдельный набор анти-паттернов отсекает то, что
   числом является, а деньгами нет: марки бензина (`залил 95`), годы выпуска,
   пробег, литры, время, даты, телефоны, размеры дисков (`R16`).
2. **Морфология.** `pymorphy3` приводит слово к нормальной форме, поэтому
   «колодки», «колодок» и «колодками» — одна и та же запись словаря. Отдельно
   разбираются фразы из двух слов («замена масла», «развал схождение») и сленг
   по началу слова («бенз», «шином», «керхер»).
3. **Опечатки.** `rapidfuzz` добивает «акумулятор» и «шиномантаж».

**Главное правило: одной суммы мало.** Нужно слово из автомобильного словаря
рядом с числом. В чате друзей числа летают постоянно — кто-то скинулся на
подарок, кто-то назвал зарплату, кто-то посчитал шаги, — и реакция на любое из
них превращала бота в спамера. Денежный маркер (`р`, `₽`, `к`) сам по себе
ничего не доказывает: «телефон за 90к» деньги, но не про машину.

Сверху три барьера потише:

- **Стоп-слова** отменяют разбор целиком. Кроме очевидных «продал», «должен»,
  «скинь», туда добавлены разговоры о ценах и планах: «подорожал», «каждые»,
  «хочу», «надо», «работает». «Бенз подорожал до 78» — это не трата.
- **Голое число без валюты** должно быть не меньше сотни. «Мойка работает до 21»
  мимо, а трат дешевле сотни почти не бывает.
- **«Штука» больше не значит тысячу.** В живой переписке это почти всегда
  «вещь»; из денежного сленга слово убрано, «косарь» и «пятихатка» остались.

Обратная сторона строгости — незнакомое слово бот пропустит. Для этого есть
явная форма: **«на тачку 3000 гидрач»**. Она записывает трату сразу, без
вопроса, и заодно учит бота слову — в следующий раз «гидрач 3000» сработает
само. Учится словарь теперь только отсюда: подтверждение через явную форму —
куда более надёжный сигнал, чем догадка.

Корпус из 22 настоящих трат и 44 обычных фраз лежит в `tests/test_noise.py` и
гоняется на каждом прогоне: он и ловит регрессии в этих правилах.

Два исправления по журналу за первые недели. Строчное «то» больше не ключевое
слово — в переписке это «что-то» и «то есть», техобслуживание ловится только как
«ТО» заглавными. И поиск опечаток работает лишь для слов, которых нет в словаре
русского языка: «делать», «капитан» и «номер» — не опечатки «детали»,
«капиталки» и «номеров». Пересланные сообщения не разбираются вовсе.

### Расход и одометр

Опечатка в одометре бывает в обе стороны, поэтому замеры чистятся не правилом
«меньше предыдущего — выкинуть», а поиском самой длинной правдоподобной цепочки:
пробег строго растёт, и машина не едет быстрее 1500 км в сутки. Всё, что в
цепочку не вошло, — опечатки.

Расход — все литры, залитые между первой и последней надёжной точкой, делённые
на километры между ними. Литры первой заправки не считаются: сколько было в баке
до неё, неизвестно. Заправки без пробега в сумму входят — их бензин сожжён на тех
же километрах. Окно — последние полгода.

### Звания

У каждого звания есть «сила» — насколько человек выделяется: лидер, обогнавший
второго вдвое, сильнее лидера с отрывом в пару процентов. Звания раздаются от
сильных к слабым, до двух на человека, причём второе — только за заметный отрыв.
Список: Чёрный лебедь, Бензоколонка, Кузнец, Любимец камер, Мойдодыр, Меценат
дорожного фонда, Дальнобой, Домосед, Танкер, Верблюд, Завсегдатай АЗС, Олигарх,
Ночной гонщик, Человек-оркестр, Ракета, Свободное падение, Скупой рыцарь.

### Журнал детектора

Каждое сообщение, где мелькнула похожая на деньги сумма, попадает в таблицу
`detect_log` — вместе с вердиктом (`keyword:мойка`, `no_keyword`, `veto:хотеть`),
найденными числами и тем, чем кончился вопрос: `yes`, `no` или `timeout`.

Пишутся и отброшенные сообщения — без них не понять, где детектор
перестраховался. Команда `/detect` отдаёт сводку с процентом попадания и полный
журнал в CSV. Через пару недель по нему видно, какие слова стоит добавить в
словарь, а какие — в стоп-лист, уже по данным, а не по догадкам.

### База

SurrealDB во встроенном режиме (`surrealkv://`): база живёт прямо в процессе
бота, отдельный сервис поднимать не нужно, данные лежат в `data/`. Если
захочется вынести её наружу — поменяйте `CARBOT_DB_URL` на `ws://…`, весь
остальной код не изменится.

Составные record id (`person:[chat_id, tg_id]`) убирают лишние поиски: запись
адресуется напрямую по чату и пользователю.

### Рендер

Картинка собирается как SVG-строка и растеризуется `resvg` — без браузера и без
внешних бинарников. Ширину текста меряет `fontTools` по тем же ttf-файлам, что
получает resvg, поэтому обрезка длинных имён и выравнивание по правому краю
совпадают с рендером точно.

Цветных эмодзи в SVG нет, поэтому категории обозначены нарисованными иконками.
Шрифт — Inter (OFL), нарезанный на четыре статических начертания скриптом
`scripts/prepare_fonts.py`.

Крутить дизайн можно без телеграма:

```bash
.venv/bin/python scripts/preview.py preview
```

Рядом с PNG кладётся `.svg` — его удобно открыть в браузере и подвигать цифры.
